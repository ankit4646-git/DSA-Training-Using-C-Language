# Assignment 08: Employee Payroll System

## Objective
To implement data structures utilizing complex conditional expressions, computational business accounting logic math pipelines, and selection sorting models[cite: 1].

## Problem Statement
Design an interactive financial accounting module managing data structures containing personal records, basic earnings scales, HRA/DA allocations, tax fields, and calculated net valuations[cite: 1]. The database computes tiered progressive taxes, constructs clean ledger data summaries, and provides in-place sorting routines based on net monthly balances[cite: 1].

## Algorithm
1. Mathematical Base Blueprinting: Declare structures mapping corporate accounting profiles.
2. Allowance Computations (O(1)): Apply standard coefficients (HRA = 0.20 \times Base, DA = 0.10 \times Base) to calculate allowance totals.
3. Progressive Bracket Taxing: Apply scale evaluations using nested conditions to verify tax rates (5\%, 12\%, or 22\%) based on Gross limits. Calculate net metrics using structural balancing arithmetic.
4. Selection Sort Sorting (O(N^2)): Scan remaining fields to find index maxima points matching net salary variables. Swap structural elements in place, minimizing deep variable context memory shifts to at most N-1 updates.

## Time and Space Complexity
* Employee Registration: Time O(1) base (O(N) structural uniqueness check) | Space O(1)
* Bracket Accounting Pass: Time O(1) | Space O(1)
* Ledger Statement Output: Time O(N) | Space O(1)
* Selection Salary Sorting: Time O(N^2) across all cases | Space O(1) auxiliary (optimized against alternative sort tracking variants due to strict minimum swap operations)
